API Reference

Comprehensive technical documentation for the Gaspol Log Viewer core API. Authenticate via Bearer Token to manage real-time streams, webhook subscriptions, and system configuration.

GET /api/v1/logs

Description

Retrieves a paginated list of system logs. Supports filtering by level, source, and timestamp ranges.

Example Request (cURL)

curl -X GET "https://api.gaspol.sys/v1/logs?limit=50&level=ERROR" \
  -H "Authorization: Bearer YOUR_TOKEN"

Example Response (JSON)

{
  "status": "success",
  "data": [
    {
      "id": "log_8x92j",
      "level": "ERROR",
      "timestamp": "2023-10-24T14:22:01Z",
      "message": "Connection timeout in primary gateway",
      "source": "api-internal-01"
    }
  ],
  "meta": {
    "total_count": 1240,
    "next_cursor": "YXA2NmI"
  }
}
POST /api/v1/webhook

Description

Register a new webhook URL to receive real-time notifications for specific log event triggers.

Body Parameters

url * string (uri)
events array[string]

Request Body

{
  "url": "https://hooks.slack.com/...",
  "events": ["error", "critical"]
}

Response (201)

{
  "id": "wh_01h82",
  "status": "active",
  "created_at": "2023-10-24T..."
}
info

Rate Limiting & Security

All requests are limited to 10,000 requests per hour per API Key. Ensure all traffic is routed over HTTPS. Tokens should be kept secret and rotated every 90 days.
