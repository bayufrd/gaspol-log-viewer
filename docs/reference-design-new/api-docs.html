Gaspol API Reference

Welcome to the official Gaspol Log Viewer documentation. Our RESTful API allows you to programmatically ingest, retrieve, and monitor system logs across distributed environments. Follow the endpoints below to integrate Gaspol into your DevOps pipeline.

GET /api/v1/logsummary/all

Retrieve All Summaries

Returns a paginated list of all log summaries aggregated by service type and severity level.

REQUEST PARAMETERS

Parameter Type Required
limit integer Optional
offset integer Optional
service string No

EXAMPLE RESPONSE

{
  "status": "success",
  "data": [
    {
      "id": "LOG_8821",
      "severity": "ERROR",
      "timestamp": "2023-10-27T10:20:00Z",
      "message": "Timeout at node_01"
    }
  ],
  "pagination": {
    "total": 1240,
    "next_offset": 50
  }
}
POST /api/v1/logs/ingest

Ingest Log Entry

Send single or bulk log objects to the Gaspol ingestion engine for processing and indexing.

BODY JSON

{
  "app_name": string,
  "payload": object,
  "tags": string[]
}

CURL REQUEST

curl -X POST \
  https://api.gaspol.sys/v1/logs/ingest \
  -H 'Authorization: Bearer [TOKEN]' \
  -d '{
    "app_name": "checkout-svc",
    "payload": {"evt": "purchase"}
  }'
